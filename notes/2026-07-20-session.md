## Decisions made (all in notes/plan.md, summarized)

- **Schema is the contract**: known event kinds store only *named* fields. No raw
  source-JSON for known types; the renderer never reads the log. Provenance
  (`source: {file, line}`) into the committed logs is the escape hatch. `raw`
  survives only on the `unknown` fallback kind.
- Every event carries: `agent` (from explicit `agentId`, else `main`), `source`
  {file,line}, `links` (uuid/parent/message/request/prompt/tool_use ids),
  `queued`, `at` (UTC).
- Assistant turns add `model`, `stop_reason`/`stop_details`/`stop_sequence`, and
  named `tokens` (input/output/cache/ephemeral_1h/ephemeral_5m/service_tier +
  `iterations` list — no raw).
- Tool events add `is_error`, `duration_ms`, named `result` fields, and
  `subagent_tokens` (from the spawning Agent call's `toolUseResult`).
- **Approval**: not present in these example logs → not emitted. Add when a newer
  log includes real approval data.
- **Hooks**: Jess is interested but deferred to a later version. Fields are noted
  in plan.md ("Deferred" section) — `system` hook/turn-duration events and the
  ~157 hook-execution `attachment` records. For v1 they stay summary-only.
- `out/` is committed; Ruby via rbenv/asdf; stdlib-first + minitest.

## Log-format facts worth keeping (details in plan.md)

- 505 records total across both episodes + their subagents.
- Subagent turns live in `subagents/*.jsonl`, flagged `isSidechain: true`, share
  the main `sessionId`, own `parentUuid` chain, and carry `agentId`. Main log has
  no `agentId`.
- Model seen: `claude-opus-4-6`. Timestamps are UTC (`...Z`).
- `attachment` records are NOT user attachments — they're hook-execution records.
